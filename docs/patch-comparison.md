# Сравнение патчей Kobo для 4.38.23852

Исходный пример — `translated/4.38.23852/KoboRoot.tgz` из `be4e4fd`. Альтернатива из `a220587` — `translated/4.38.23852/old patch.zip`, внутри которого ровно один `KoboRoot.tgz`. Сравнивалось содержимое внутренних tar-архивов. Для `trans_ru.qm` проверено только расположение, не содержимое. Скрипт не запускался.

| Что проверено | Исходный пример | Альтернатива |
|---|---|---|
| Структура tar | 9 обычных файлов, без записей каталогов | 12 обычных файлов и 10 записей каталогов |
| Путь перевода | `usr/local/Kobo/translations/trans_ru.qm` | Тот же |
| Шрифты | 8 TTF в `usr/local/Trolltech/QtEmbedded-4.6.2-arm/lib/fonts/` | Те же пути и имена; SHA-256 совпадает для каждой пары файлов |
| Переносы слов | Нет | `usr/local/Kobo/hyphenDicts/hyph_ru.dic` — русский словарь переносов (90 755 байт) |
| Автоматические действия | Нет | Правило `etc/udev/rules.d/delete_fonts.rules` и скрипт `root/delete_fonts.sh` |
| Владелец и права | UID/GID `0:0`; файлы `0644` | UID/GID `0:0`; файлы **и каталоги** `0777`, в том числе записи `etc/` и `root/` |

**Шрифты.** В обоих патчах Avenir представлен файлами `Avenir.ttf`, `Avenir-Bold.ttf`, `Avenir-Italic.ttf`, `Avenir-BoldItalic.ttf`; Georgia — `georgia.ttf`, `georgiab.ttf`, `georgiai.ttf`, `georgiaz.ttf`. Набор начертаний и сами файлы не меняются.

**Что делает скрипт.** Правило udev при событии для `loop0` вызывает `/root/delete_fonts.sh`. Скрипт пытается удалить `KBJ*` из **другого каталога**, `/usr/local/Qt-5.2.1-arm/lib/fonts/`, после чего удаляет правило и самого себя. Это удаление системных шрифтов, а не установка Avenir или Georgia. Как и когда правило сработает на конкретном устройстве, не проверялось.

**Вывод для сборки.** Сохраняем минимальный состав исходного примера: перевод и восемь шрифтов. Словарь переносов — отдельное дополнение. Правило, скрипт удаления и режим `0777` не нужны для установки перевода и в сборку Actions не включены. Особенно нежелательны записи системных каталогов с такими правами: при распаковке с восстановлением метаданных они могут изменить права уже существующих каталогов устройства.
