# Русификация Kobo

Готовый перевод для прошивки **4.38.23852** устанавливается как патч `KoboRoot.tgz`.

## Извлечение исходника из новой прошивки

Рабочая папка — **корень репозитория**. Положите сюда `kobo-update*.zip`. На Windows запустите двойным щелчком [py_script/translate.cmd](py_script/translate.cmd): он сам перейдёт в корень и найдёт Python 3 (`py -3` или `python`). Qt для работы скриптов не нужен.

| Пункт меню | Действие и результат |
|---|---|
| 1 | Из ZIP извлекается только `KoboRoot.tgz → usr/local/Kobo/nickel`, затем из `nickel` — каталоги Qt. Для `kobo-update-4.38.23697 aura.zip` результаты лежат в `src/4.38.23697/`: `nickel_<смещение>.qm`. Распакованный `nickel` временный: в каталоге результатов он не остаётся. Номер берётся из имени архива, а не вводится вручную. |
| 2 | Выберите по номеру папку прошивки из `src/` (новые версии идут первыми; `0` — назад). Затем выберите по номеру английский `trans_en.qm` прежней прошивки для сверки из другой номерной папки. При побайтовом совпадении скрипт сразу сообщит, что новый перевод не требуется. В остальных случаях скрипт преобразует все извлечённые `nickel_<смещение>.qm` во временные `.ts` и сначала ищет каталог с `/TS/@language="en"`. Если такой метки нет, каталоги без языка сверяются с английским образцом (см. ниже). При успехе остаются `src/<версия>/trans_en.qm` и `.ts`. Исходники со смещениями удаляются **после** сохранения пары. Если совпадение недостаточно надёжно или подходят несколько каталогов, скрипт не угадывает язык и не удаляет исходники. Без образца доступен поиск только по метке языка. |
| 3 | Выберите по номеру целевую папку версии из `src/`, затем папку прежнего перевода из `translated/`. Во втором списке только версии с `trans_ru.qm`; Enter создаёт шаблон без перевода, `0` возвращает в меню. Результат сохраняется в `translated/<целевая версия>/trans_ru.ts`. Список непереведённых сообщений с именами контекстов сохраняется рядом с каталогами: `translated/<версия>/untranslated.txt`. Блок лицензий `Attributions` остаётся без перевода и не попадает в отчёты. **Отредактируйте `.ts`** по [правилам перевода](TRANSLATION.md). |
| 4 | Выберите папку версии из `translated/` и скомпилируйте `translated/<версия>/trans_ru.qm`. Публикация изменений и сборка патча через Actions — отдельно, как описано ниже. |
| 5 | Необязательно: выберите версию из списка, для которой есть оба `.ts`. Сравниваются английский и русский каталоги **одной версии**. Отклонения длины сверх порога записываются в `reports/<версия>/lengths.txt` (UTF-8). |
| 6 | Выберите версию с русским `.qm` и соберите установочный `KoboRoot-<версия>.tgz` локально в `build/` (Python 3; работает без Qt и не требует GNU tar). |

Для командной строки на любой платформе из корня репозитория:

```sh
python3 py_script/bin2qm.py
# Если архивов несколько, укажите нужный явно:
python3 py_script/bin2qm.py "kobo-update-4.38.23697 aura.zip"
```

Если в локальной папке `src/<версия>/` уже есть выбранные файлы `trans_en_<версия>.qm` и `trans_en_<версия>.ts`, переименуйте их в `trans_en.qm` и `trans_en.ts` соответственно. Повторно распаковывать прошивку не нужно.

Если после прежней распаковки в `src/<версия>/` уже лежат `nickel_*.qm`, сразу запустите пункт 2. В исходном английском QM версии 4.38.23852 язык не записан; атрибут `language="en"` был задан при создании [эталонного TS](src/4.38.23852/trans_en.ts). Для файлов без метки пункт 2 сравнивает с выбранным английским QM **значения перевода**, а не только английские `source`: учитываются контекст, исходная строка, комментарий и все формы числа. Требуется не менее 50 общих переведённых ключей, совпадение не менее 90% из них и не менее трёх совпавших сообщений с различающимися формами числа. Число совпадений выводится для каждого проверенного файла. Только при единственном результате скрипт записывает `language="en"` в итоговый TS; выбранный QM сохраняется без изменений. При неоднозначности для ручной сверки можно выгрузить любой каталог командой `python3 py_script/qm2ts.py <кандидат.qm> <кандидат.qm> <проверка.ts>`: без четвёртого аргумента язык берётся только из метаданных. Не указывайте `en` для непроверенного файла.

Существующая папка результатов не перезаписывается. Для другого устройства той же версии или ZIP без номера можно указать отдельную новую папку через `-o`. Без ZIP скрипт по-прежнему может разобрать отдельный `nickel` (по умолчанию в `extracted-qm/`, поскольку версия неизвестна). Архив прошивки, `nickel` и неотобранные `nickel_*.qm` не нужно добавлять в Git.

## Обновление перевода и сборка в Actions

1. Обновите `translated/<версия>/trans_ru.qm`. Если редактировали `.ts`, сначала скомпилируйте его, например:
   ```sh
   python3 py_script/ts2qm.py translated/4.38.23852/trans_ru.ts translated/4.38.23852/trans_ru.qm
   ```
2. Отправьте изменения (`git push`). При изменении `.qm`, шрифтов, словаря переносов или файлов сборки workflow **Build KoboRoot.tgz** соберёт **один патч** для самого большого номера версии в `translated/`. Компоненты номера сравниваются как числа (`4.40.10` новее `4.40.9`); если у новейшей версии нет готового `.qm`, сборка завершится ошибкой, а не выпустит старую версию. Сборку можно также запустить вручную через **Actions → Build KoboRoot.tgz → Run workflow**.
3. Откройте завершённый запуск и в разделе **Artifacts** скачайте `KoboRoot-<версия>` для своей прошивки. Распакуйте скачанный ZIP и скопируйте **сам `KoboRoot.tgz`**, не распаковывая его, в каталог `.kobo` на устройстве. Безопасно извлеките устройство для установки.

Патч доступен как артефакт Actions; его не коммитят и не помещают в `translated/`. Локально соберите его пунктом **6** интерактивного меню: выберите прошивку, а результат появится в `build/KoboRoot-<версия>.tgz`. Также можно запустить кроссплатформенный сборщик вручную (Python 3, без Qt):

```sh
python3 scripts/build_patch.py translated/4.38.23852/trans_ru.qm build/KoboRoot-4.38.23852.tgz
tar -tzf build/KoboRoot-4.38.23852.tgz
```

`build/` — временный каталог, исключённый из Git. `scripts/build_patch.sh` остаётся вариантом для Linux-сборки/CI.

## Состав патча

- `usr/local/Kobo/translations/trans_ru.qm` — перевод выбранной версии.
- `usr/local/Kobo/hyphenDicts/hyph_ru.dic` — правила русских переносов из альтернативного патча; исходный файл хранится в `patch/hyphenDicts/`.
- `usr/local/Trolltech/QtEmbedded-4.6.2-arm/lib/fonts/` — восемь файлов Avenir и Georgia из исходного патча 4.38.23852. Для сборки они хранятся в `patch/fonts/`.

[Скрипт удаления шрифтов и правило udev](reference/legacy-scripts/README.md) сохранены отдельно для справки и в патч не входят.

## Файлы репозитория

- `src/4.38.23852/trans_en.qm` — английский исходник, извлечённый из `usr/local/Kobo/nickel` прошивки 4.38.23852.
- `translated/<версия>/` — только `trans_ru.ts` и `trans_ru.qm`. Заметки по конкретной версии и скриншоты оставляйте в обсуждении задачи или pull request.
- `py_script/` — инструменты на Python 3, не требующие Qt:
  - `ts2qm.py` — компиляция `.ts` → `.qm`;
  - `qm2ts.py` — преобразование `.qm` → `.ts` с полным списком строк прошивки;
  - `qmtool.py` — поиск и разбор `.qm` внутри `nickel` (`python3 py_script/qmtool.py find <папка> nickel`);
  - `qmwrite.py` — запись `.qm` в формате `lrelease`.

## Сверка перевода 4.38.23852

[Английский каталог в формате Qt Linguist](src/4.38.23852/trans_en.ts) можно читать и сравнивать с русским `.ts`, не устанавливая Qt. Чтобы повторить выгрузку, передайте английский `.qm` как каталог перевода и как список ключей:

```sh
python3 py_script/qm2ts.py src/4.38.23852/trans_en.qm src/4.38.23852/trans_en.qm src/4.38.23852/trans_en.ts en
```

Порядок проверки каталогов описан в [правилах перевода](TRANSLATION.md).
