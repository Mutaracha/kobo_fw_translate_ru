# Справочные файлы старого патча

`delete_fonts.rules` и `delete_fonts.sh` сохранены без изменений из `old patch.zip` (коммит `a220587`). Правило udev вызывает скрипт при событии `loop0`. Скрипт удаляет системные шрифты `KBJ*`, затем удаляет правило и себя. Это **не часть установки переводов или переносов**: файлы не запускаются при сборке и не попадают в `KoboRoot.tgz`.
